# Jotter v2.7.5 Release Notes

## What's Changed

### Clipboard Tab — buttons moved to the left
Each line's **Copy** and **×** (remove) buttons now sit on the **left** side of the line, followed by the color dot and then the text box. Previously they were on the right. They now stay in the same place however long a line is, so they're easier to reach.

### Fixes
- The frame holding a line's Copy/× buttons now follows Dark/Light mode switches. Before, it kept the previous theme's background.

---

## Installation

Jotter now ships as a standalone `Jotter.exe` with no installer. Download it from the releases page and run it, or run from source:

```bash
pip install tkinterdnd2
python editor.py
```
